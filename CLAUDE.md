# CLAUDE.md — ecmexplainer

The ECMExplainer Shiny app and reference implementation (Sheekey, Avelar, Fujiwara).
Analysis and review work for the manuscript lives in `../ecmexplainer-manuscript`.

- `supplementary/SI_Table*.xlsx` are the published tables and the ground truth.
  Any change to `R/ecm_core.R` must keep these passing:
  `Rscript tests/test_manuscript_numbers.R`, `tests/test_validation.R`,
  `tests/test_app_server.R`, `tests/test_app_smoke.R`, `scripts/build_models.R`.
- Selection order matters: ties in TSP delta are broken by eta order and pair
  enumeration (alphabetical for ADSIG/POOL, variance order for ALLGENE).
  A re-implementation that enumerates pairs differently selects a different panel.
- `data/TrainedModel_ADSIG_180.rds` is the published model: never rewrite it.
  POOL-180 and ALLGENE-180 are rebuilt by `scripts/build_models.R`.
- `data/validation_expr.rds` is generated by
  `../ecmexplainer-manuscript/analyses/official_sup_review/scripts/04_bundle_validation.R`.
- Deployed at https://apps.avelar.science/ecmexplainer/ (Docker on the Hetzner VPS,
  port 3838, `ECMX_MODE=web`). The repo is private until publication; only
  Roberto changes its visibility.
